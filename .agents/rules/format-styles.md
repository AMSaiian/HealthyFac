# Stylesheet Formatting Rules (.editorconfig)
*   **Indentation:** 2 spaces per indent.
*   **Quotes:** Use **single quotes** for SCSS/CSS values (`use_double_quotes = false`).
*   **Hex Colors:** Use **upper-case** for Hex colors (`hex_color_upper_case = true`) and prefer the long format.
*   **Braces:** Place opening braces at the end of the line.
*   **Alignment:** Do **not** align closing braces with properties (`align_closing_brace_with_properties = false`).
