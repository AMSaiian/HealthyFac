# Stylesheet Formatting Rules
*   **Tools:** Prettier enforces indentation, quotes, braces, and alignment. The Stop hook runs it.
*   **Hex Colors:** Use **upper-case** for Hex colors (`hex_color_upper_case = true`) and prefer the long format. No tool checks it.
