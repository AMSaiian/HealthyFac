# HTML Code Formatting Rules (.editorconfig)
*   **Indentation:** 2 spaces per indent.
*   **Quotes:** Use **double quotes** for attributes (`quote_style = double`).
*   **Alignment:** Do **not** align attributes with extra spaces (`align_attributes = false`). Wrap attributes to new lines on every item if too long.
*   **Empty Tags:** Include a space inside empty tags before the closing slash (e.g., `<br />`).
