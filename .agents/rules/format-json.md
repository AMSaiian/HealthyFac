# JSON Formatting Rules (.editorconfig)
*   **Indentation:** 2 spaces per indent.
*   **Wrapping:** Split object properties and array elements into separate lines (`object_wrapping = split_into_lines`).
*   **Alignment:** Do **not** use extra spaces to align property values (`property_alignment = do_not_align`).
